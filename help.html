KnowFlow

Select a term, open an AI knowledge card, and follow related concepts side by side.

Getting started

  1. Select a word or phrase on any page. A small spark button appears next to the selection.
  2. Click the button. KnowFlow opens a compact card with an explanation, related concepts, and source searches.
  3. Explore deeper. Click any related concept to open another card beside the current one. You can also select text inside a card.
  4. Dismiss cards with the close button, or click elsewhere on the page to clear the stack.

Model setup

Open the extension popup and choose a model:

  • Free · GPT-OSS 20B (no key): the default. Uses an open-source model with no setup. It is rate-limited (about one request every 45 seconds) and slower, so it suits occasional lookups.
  • Use your own API key: for faster, unlimited lookups. Pick a provider (Google Gemini, OpenRouter, Groq, DeepSeek, OpenAI, or a custom OpenAI-compatible endpoint), paste your key, and the model and endpoint fill in for you. Several providers have a free tier. Your key is stored only on this device and never synced.

Output language

KnowFlow defaults to English. You can switch the output language in the popup. The selected term keeps its standard spelling.

Save to Obsidian

Each knowledge card has a Save to Obsidian button. It creates a Markdown note through Obsidian URI with the explanation, related concepts, sources, original page URL, and capture time. Add a vault name in the popup if you want notes to open in a specific vault.

Site controls

Use Active on this site to disable KnowFlow on the current domain. Use Enable extension to turn it off everywhere.

Privacy note: KnowFlow sends the selected term and nearby text context to the model provider you choose. Your API key is stored only on this device (local storage) and is never synced. Do not use it on pages with sensitive personal, company, or client information.

Where it works

Regular web pages, local HTML files after enabling file URL access, and text inside frames where Chrome allows content scripts.
